# Referências de UI/UX

Imagens de referência visual para o site (mockups, telas de outros apps,
inspirações de layout/cor/tipografia, etc.).

**Convenção**: antes de fazer mudanças na interface (redesign, novo
componente, ajuste visual), consultar as imagens desta pasta para manter
consistência com a direção visual definida pelo usuário.

## Imagens

- **syncboard-dashboard-kanban.webp** — dashboard "Syncboard": fundo com
  gradiente azul/roxo atrás do card do app; sidebar com ícones + labels;
  colunas Kanban (To Do/In Progress/Review/Complete) com badge de contador;
  cards de tarefa com tags coloridas por área (Frontend/Backend/QA/Design),
  barra de progresso fina, avatares empilhados dos responsáveis.
- **trello-dark-mode.png** — Trello em dark mode: fundo com gradiente
  vibrante atrás das listas; colunas simples com contador; cards com
  thumbnail de imagem no topo.
